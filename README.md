# Hassan Javed Durrani: portfolio

Static site (no build step). Open `index.html` or upload the folder to any host.

- `index.html`: all content
- `assets/css/style.css`, `assets/js/main.js`: styles and behaviour (no frameworks)
- `assets/fonts/`: self-hosted Bricolage Grotesque, Figtree, JetBrains Mono
- `assets/img/about-classic.webp`: compressed about-section portrait
- `robots.txt`, `sitemap.xml`: crawl files (update the URLs if the site moves to a custom domain)
- `assets/img/projects/`: Search Console and Google Ads screenshots
- `assets/docs/Hassan_Javed_Durrani_CV.pdf`: CV (email updated to hassan@digitalwasfa.com)

The contact form opens the visitor's email app addressed to hassan@digitalwasfa.com, so it works on any static host.
